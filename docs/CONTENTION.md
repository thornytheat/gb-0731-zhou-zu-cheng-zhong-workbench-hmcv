# 争配裁决规则（整车证据取舍）

晚班同车同侧多条轮载争用同一对侧轮载时，**不允许在局部挑时间最近的一组**。局部贪心会让轴距、偏载和磅单差额互相矛盾，并造成整车少轴、无法核平。本规则在整车（车次）范围内统一裁决。

## 1. 候选与枚举

- 配对时窗仍为对侧 ±35 ms（`PAIR_MS`），窗内的对侧轮载都是候选边。
- 在整车范围内枚举所有**一对一**合法配对方案：每条轮载最多属于一根轴，允许某条轮载在某方案中暂不配对（用于暴露缺轴方案）。
- 方案按轮载时刻、源行、记录号做确定性排序，保证同一输入的枚举顺序恒定。

## 2. 整车证据字典序

对每个方案依次比较，靠前的维度优先：

1. **成轴数**：越多越优。整车少轴直接破坏核平，是第一硬证据。
2. **轴距违规数**：相邻轴推算轴距须落在 `[0.55, 12]` m；中间夹着未配对触发时不穿缺证区间推距。
3. **偏载轴数**：先比严重（≥20%）轴数，再比预警（≥10%）轴数，越少越优。
4. **磅单差额绝对值**：`|静态总重 − 方案轮载合计|`，越小越优。无有效磅单（缺失、版次冲突、车牌/时间不符、坏单）时记**中性**，不参与裁决，绝不能把缺证当成最优理由。
5. **确定性回退**：总偏时、配对记录号序列。仅用于在证据并列时稳定展示，**不是证据，不能据此宣布已解决**。

## 3. 裁决结论

- 存在**唯一**证据最优方案 → `resolved`：采用该方案，落选轮载按 `PAIR_MISSING` 缺证隔离，车轴标记为已确认。
- 证据并列、无唯一最优 → `blocked`：
  - 卷入争配的轮载全部挂起，原因码 `PAIR_CONTENDED`，互相关联证据；
  - 车轴以 `tentative`（争配挂起）展示，**不做轴距判废、不做偏载判级**（M5 判级为 `blocked`，不给出偏载率与重侧）；
  - M6 整车勾稽附 `AXLE_CONTENDED`，**即使整车差额为 0 也强制待复秤，不得核平**。

## 4. 上游更新与重算

- 批次键包含四份源文件 SHA-256、规则版本与参数。任一轮载记录更新都会改变触发文件摘要，生成新批次键：相关车轴、偏载判级和整车勾稽结论随整批重算；旧批次作为历史快照保留、不被改写。源文件变化下对旧批次重跑返回 `SOURCE_CHANGED`。
- 争配枚举与排序是无副作用的纯函数。同一输入重跑得到完全相同的裁决状态、采用配对与排除候选集合；已排除候选不会在重跑中被第二次计入，也不会换一套配对再判。

## 5. 守恒口径

原始触发 = 有效触发 + 重复触发 + 隔离触发 仍然成立。争配挂起车轴的轮载是有效采样，计入有效轮载守恒；落选与缺证轮载计入隔离。`blocked` 不破坏数量守恒，只冻结判级与核平两类结论。

## 6. 边界与不覆盖

- 枚举规模单车次有界（晚单车次轮载数小），回溯枚举可接受；超大车次需在 M1 的 4,000 条上限内受控。
- 现场复秤后的人工取舍在外部系统登记，本工作台只提供候选方案、证据与排除台账，不替代人工终裁。
